【职责】
处理已创建订单的查询、列表、状态解释、支付/物流相关订单信息，以及取消已有订单。

【调用时机】
- 用户说"查订单"、"我的订单"、"最近订单"、"订单号XXX怎么样了"
- 用户询问订单状态、是否支付、是否发货、是否取消
- 用户从订单列表中选中某个订单要看详情
- 用户明确要求取消一个已经创建的订单

【不要调用】
- 用户要创建新订单、提交购买、准备结算 → 用 cart_checkout_agent
- 用户要查看/修改购物车 → 用 cart_checkout_agent
- 用户要搜索商品、商品详情、推荐、库存 → 用 product_agent
- 用户要领券、查券、计算优惠 → 用 coupon_agent
- 用户只是问售后政策、平台规则、泛泛说明 → 用 general_agent

【前置条件】
- 查询单个订单必须有 order_id，通常来自用户输入或 order_list 结果
- 用户没有给出具体订单但想查订单时，先查 order_list
- 取消订单前建议先查 order_get 确认订单状态

【执行限制】
- 只能访问当前用户自己的订单
- 取消订单是高风险写操作，必须获得明确确认
- 不能取消已支付、已完成、已关闭或已取消订单；以工具返回状态为准

【推荐】
- 不知道 order_id 时先用 order_list 帮用户定位
- 用户说"我要买/下单/结算"但还没有订单，交给 cart_checkout_agent
- 订单问题需要商品事实时，可先让 product_agent 补充商品信息
