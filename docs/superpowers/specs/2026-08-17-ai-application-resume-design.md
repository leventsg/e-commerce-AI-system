# AI 应用工程师单页简历设计

## 目标

基于候选人旧版 Golang 后端简历和当前 `go-mall` 仓库，生成一份面向 2027 届秋招校招的 AI 应用工程师简历。简历使用 A4 单页、高密度单栏布局，保留证件照，并将 AI 智能客服作为主叙事。

## 输入与事实来源

- 旧简历：教育、联系方式、实习经历、既有项目描述、技能和证件照。
- 仓库文档：AI 客服 PRD、技术方案、实施计划及上下文记忆设计。
- 仓库实现：Eino ADK 多 Agent 编排、工具注册与执行、SSE、分层记忆、高风险确认、Checkpoint、审计和电商微服务底座。
- 用户明确给定的项目设定：Redis 缓存记忆、Agent Skill、MCP 集成和 Agent 评估能力已实现。

不新增未经材料支持的公司、职位、教育经历、用户规模、性能比例、准确率或业务收益。用户给定的 Skill、MCP 和评估能力可以作为已实现能力描述，但不为其编造量化结果。

## 岗位定位

采用“AI 应用落地型”定位：突出模型编排、Agent 工程、工具调用、上下文记忆、安全治理和评估闭环，同时用 Go 微服务、电商交易链路与后端实习证明真实系统交付能力。

一句话定位：深圳大学计算机技术硕士（2027 届），具备 Go 微服务与 LLM Agent 应用落地经验，能够完成从模型编排、工具与记忆系统到业务 RPC、安全审计和评估回归的端到端交付。

## 信息架构

页面按以下顺序组织：

1. 顶部信息：姓名、`2027 届｜AI 应用工程师`、联系方式、GitHub 和右侧证件照。
2. 教育背景：深圳大学硕士和西南科技大学本科各一行，保留 GPA 与硕士奖学金。
3. 个人优势：两行以内概括 Go 微服务和 LLM Agent 的复合能力。
4. 核心项目：`go-mall 智能电商 Agent｜2025.12—至今`，占页面最大篇幅。
5. 实习经历：小鹅通 Golang 后端开发实习，保留三条最强工程证据。
6. 专业技能：按 AI 工程、Go 后端、数据与中间件、工程工具分组横排。

删除旧简历中的课程罗列、泛化个人评价和兴趣爱好，避免第二页或信息稀释。

## 核心项目叙事

项目简介：面向商品、库存、订单、购物车、结算和优惠券业务构建可执行的智能客服 Agent，通过自然语言完成查询、推荐、低风险操作和高风险确认。

项目要点：

1. 基于 Eino ADK 构建 Supervisor 与 5 个领域 Agent，通过 AgentTool、ToolsNode 和领域工具白名单完成任务拆解与协作。
2. 设计统一能力链路，管理核心 20 个业务 Tool 与 2 个记忆能力 Tool；将本地 Tool、Skill 和 MCP 外部能力纳入统一权限、超时、参数校验和审计策略。
3. 实现 `MemoryProvider + MemoryMiddleware` 分层上下文，组合近期消息、滚动摘要、长期事件、用户画像和工具事实；通过 Kafka 异步更新画像与长期记忆，组件异常时降级而不阻塞聊天。
4. 对创建订单、取消订单等高风险操作接入 StatefulInterrupt、Redis 短锁、MySQL CAS 和 Checkpoint 恢复；从认证上下文注入用户身份，拒绝越权、过期和重复执行。
5. 建立覆盖路由、工具选择与参数、安全规则、记忆召回和回答质量的评估集与回归流程；以 Redis Lua、DTM Saga、Kafka、Elasticsearch/Gorse 等电商底座提供可执行业务场景。

措辞使用“构建、设计、实现、接入”，不使用未经确认的“主导、负责人、Owner”。

## 实习经历取舍

保留以下三组证据：

1. Goroutine 并发拉取和按需懒加载，将核心接口响应从 800ms 降至 350ms。
2. 多级数据聚合与 Doris 缺失指标补全，通过结果集缓存降低 Doris 查询频率 40%。
3. 字段预检、分页拉取、Redis 队列、后台协程、Kubernetes 分发、数据库游标和 Kafka 回传组成的异步导出链路。

指标全生命周期审批流可在版面允许时作为第四条，否则从正文删除并保留在面试素材中。

## 视觉规范

- A4 单页、单栏主体、白色背景、深灰正文和科技蓝分区线。
- 顶部右侧放证件照，保持原始比例并使用 `object-fit: cover`。
- 姓名、目标岗位、分区标题、项目标题、关键技术与真实指标形成有限层级。
- 不使用技能进度条、星级、图表或大面积装饰色块，确保 ATS 解析和黑白打印可读。
- 正文字号保持正常投递可读范围；通过压缩冗余和行距控制页数，不使用不可读的小字号。

## 可编辑与打印行为

- HTML 正文为真实文本，支持选择、复制和浏览器内编辑。
- 页面外提供编辑/保存提示和打印按钮；工具栏在 `@media print` 下隐藏。
- 打印 CSS 固定 A4 尺寸、页边距和单页布局，避免响应式样式在打印时改变结构。
- PDF 必须保留可选择文本，不以整页截图代替。

## 输出

- 单页可编辑 HTML。
- 单页 PDF。
- 内容与证据审计说明，包含岗位定位、HR 开场白、完整自我介绍、强主张证据和可能追问。

当前 `/resume` skill 的官方 18 套模板资源未随安装提供，因此使用后备 A4 模板。后备模板不承诺官方模板复刻精度，但保留完整的编辑、打印和 PDF 导出能力。

## 验收标准

- PDF 恰好 1 页，纸张为 A4，无额外空白页。
- 工具栏、编辑提示和调试元素不出现在 PDF 中。
- 证件照比例正常；姓名、邮箱、GitHub、项目标题和长技术词不溢出。
- HTML 和 PDF 正文均可选择、复制；中文字体显示正常。
- 页面在开启或关闭背景图形时均可读。
- 项目描述与仓库实现或用户明确给定的设定一致，不包含未经确认的量化结果。
- 旧简历中的真实教育、实习时间和已有量化指标保持一致。
