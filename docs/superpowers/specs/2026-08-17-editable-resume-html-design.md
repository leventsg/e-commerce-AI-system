# 可编辑简历 HTML 复刻规格

## 目标

将 `levent-简历2.pdf` 转换为仓库根目录下的一份单页 A4 HTML 简历。HTML 必须保留原 PDF 的内容、头像、蓝黑配色和信息层级，同时保证文字可选择、复制和直接编辑。

## 实现方案

- 使用语义化 HTML 重建姓名、联系方式、教育背景、实习经历、项目经历和专业技能。
- 使用 CSS 复刻原 PDF 的单栏紧凑布局、蓝色分节标题、分割线、列表间距和头像位置。
- 页面主体使用 A4 固定纸张尺寸；屏幕端显示页面阴影，打印端隐藏工具栏并移除阴影。
- 提供“开启/关闭编辑”按钮，通过 `contenteditable` 控制简历正文；不引入框架或外部运行时依赖。
- 使用本地嵌入或同目录资源保存头像，避免依赖网络。

## 内容边界

- 按源 PDF 原文录入，不美化、不扩写、不虚构经历或指标。
- 不将整页 PDF 或截图作为页面背景；所有简历文字均为真实 HTML 文本。
- 对无法可靠辨认的字符进行人工复核；仍无法确认时保留明确的待确认标记。

## 验收

- 浏览器中所有文字可选中，开启编辑后可直接修改。
- 打印为 A4 时保持单页，无工具栏、溢出、遮挡或额外空白页。
- 姓名、联系方式、头像、分节顺序和经历条目与源 PDF 一致。
- 在无网络环境下可正常打开和打印。
